影学者 — 浏览器中的 AI 阅读与学习助手

使用你自己配置的 OpenAI 兼容 AI 服务，为选中文字提供解释、总结网页，并在侧栏中继续讨论。

主要功能
• 划词悬浮入口与右键分析。
• 侧栏对话、流式输出、Markdown、表格和复制按钮。
• 解读模式提供解释；思路模式提供引导提示。
• 截图模式用于翻译或解释当前可见网页。该模式下每次请求都会把新的网页截图发送给配置的服务商，需要支持图像的模型。
• 中英文界面与可编辑的模式提示词。
• 可选文字选择辅助，在编辑器外保留复制、选择和右键菜单，不改写粘贴、焦点、页面可见性、计时或脚本执行。

配置自己的 AI 服务
填写 API 地址、模型 ID 和 API 密钥，可连接 OpenAI、OpenRouter、DeepSeek、兼容网关或本机 Ollama。扩展不提供 AI 账号或 API 额度，服务商可能收费。远程服务必须使用 HTTPS；HTTP 仅限本机服务。不直接支持原生 Anthropic Messages 接口。

本机模型与隐私
连接本机 Ollama 等本地模型，且服务不将请求转发至云端时，发送的内容和生成的回答都留在本机。只填写 localhost 并不保证离线；请确认本地服务与所选模型的配置。

数据用途与控制
你请求 AI 帮助时，选中或提取的网页文字、输入的消息、对话上下文、提示词，以及截图模式的当前可见截图，会直接发送到你配置的端点。服务商还会接收 API 密钥与网络信息，并可能按其政策保留请求。截图可能包含可见的个人信息，请在发送前检查。

开发者没有后端，不会收到提示词、密钥、截图或回答；扩展不包含分析或广告遥测。首次请求前需同意设置中的数据披露，更换 API 地址后需重新同意。

API 密钥仅保存在浏览器会话内存，重启 Chrome 或重新加载扩展后需重新填写。偏好设置、最多 50 条内联问答和 100 条待同步记录保存在本机，并有额外大小限制。设置中提供清除本地问答与待处理请求的按钮。截图不会写入扩展历史。清除本地数据无法删除服务商已保留的请求。

网站访问权限用于划词界面、主动请求的页面提取与截图、自定义 API 连接。不会自动在后台上传网页。部分浏览器内部页面和应用商店页面不支持扩展操作。
